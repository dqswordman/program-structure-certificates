# Maintenance

The v1.0.0 tag identifies the frozen first artifact. The main branch can receive clarifications and verified examples. Changes to evidence or numerical outputs go into a separately versioned release with an updated file manifest and verification report.

Record the arXiv identifier and URL in docs/release-manifest.json and the README when the preprint has a public arXiv record. Use the same GitHub repository URL. Retain the existing tag and record new versions separately. Finalize the original assets' reuse terms and record the retrospective archive's disposition before public distribution. The author's website entry can then reference the published preprint and verified artifact version.
